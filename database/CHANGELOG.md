# [1.1.0] - 2026-08-31

## Changed — Database platform

The AUSTRC central database implementation was changed from the original MySQL 8.0-oriented DDL to **Neon PostgreSQL**.

### Logical architecture

No business table was added or removed.

```text
Total:          56
Shared/Core:    14
Event:          20
Administration: 22
```

Module ownership and business relationships remain unchanged.

### PostgreSQL DDL conversion

Changed:

```text
MySQL AUTO_INCREMENT
    -> PostgreSQL GENERATED BY DEFAULT AS IDENTITY

LONGTEXT
    -> TEXT

JSON
    -> JSONB

TIMESTAMP
    -> TIMESTAMPTZ

UNIQUE KEY name (...)
    -> CONSTRAINT name UNIQUE (...)

KEY index_name (...)
    -> CREATE INDEX index_name ON ...

ON UPDATE CURRENT_TIMESTAMP
    -> PostgreSQL set_updated_at() trigger pattern
```

### Neon operational baseline

- Database credentials are provided through environment variables.
- Application code uses a Neon PostgreSQL connection string.
- Production schema changes remain migration-controlled and Git-reviewed.
- Neon hosting does not change table ownership rules.

- `README.md`

- `DATABASE_RULES.md`
- `TABLE_OWNERSHIP.md`

```text
Event -> Shared/Core          allowed
Administration -> Shared/Core allowed
Event -> Administration      forbidden

Shared/Core -> modules        forbidden
```
